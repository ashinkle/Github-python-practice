Python Practice

A collection of small Python exercises I wrote while learning the language.

Files
File	Description
calculator.py	A command-line calculator that adds, subtracts, multiplies, and divides two numbers.
How to Run

Make sure you have Python 3 installed, then run:

bash
python calculator.py

Follow the on-screen menu: pick an operation, enter two numbers, and see the result. Type q to quit.

What I Practiced
Writing and calling functions
Using while loops for a repeating menu
Handling user input and errors (try/except)
Using dictionaries to organize menu options
Guarding against division by zero
